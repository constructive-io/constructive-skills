## AuthzAllowAll

Anyone who can use the table gets every row, with no check.

**Parameters**

No parameters.

**Use when**

- Reference data that every signed-in person may read, such as a list of countries.

**Avoid when**

- Any operation that changes rows: anyone who can use the table could change or delete every row.

**Risks**

- On create, update or delete it lets anyone who can use the table change every row.

**Use when**

- A private list per person in the app: use it for read, create, update and delete.
- App-wide rows that only their author may change: use it for update and delete.

**Avoid when**

- Only admins may set a flag such as is_shared or is_published.
- Only some changes are allowed, such as member to admin.
- With the immutable pattern, nobody may change the column after the row is made.

**Avoid when**

- Hiding a column from a role completely: leave the column out of that role's grant instead.

**Use when**

**Avoid when**

**Use when**

- Rows that belong to an organization or a team, where every member may take part.
- Rows a person keeps for themselves: every user has a personal organization whose id is their own id.

- Every person also has an organization of their own (its id is their user id), so any active member of the app passes for rows that name it.
